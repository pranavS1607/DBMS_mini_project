# SQL Query Catalog

`sql/09_demo_queries.sql` contains 25 numbered, executable Oracle queries. It covers selection, pattern matching, joins, aggregates, `GROUP BY`, `HAVING`-style analytical criteria, subqueries, correlated queries, ledger reports, valuation, performance, audit review, watchlists, price history, and a holdings-to-ledger reconciliation. Each query has a one-line purpose directly above it; keep this document and the script synchronized when adding report features.
